# Security

Found a way to misuse Omnivix, such as making the server fetch something it shouldn't or getting around the export limits? Here's how to report it.

## How to report

Don't open a public issue. Instead, open the repository's **Security** tab and choose [Report a vulnerability](https://github.com/marhjoh/omnivix/security/advisories/new). Only the maintainer can see the report.

Include:

- What's affected (a page, an API route or a file)
- How to reproduce it
- What an attacker could do with it

## Scope

- The code in this repository
- The site at [omnivix.vercel.app](https://omnivix.vercel.app)

## Disclosure

Omnivix is a hobby project, so replies are best effort, but every report is read. Once a fix is released, the advisory is published and credits you, unless you'd rather stay anonymous.
