# Security

Please report vulnerabilities privately, not in a public issue: go to the repository's **Security** tab and choose [Report a vulnerability](https://github.com/marhjoh/omnivix/security/advisories/new).

This covers the code in this repository and the site at [omnivix.vercel.app](https://omnivix.vercel.app). Omnivix is a hobby project, so replies are best effort, but every report is read.
